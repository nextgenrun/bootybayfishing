# 🎣 Booty Bay Fishing

A single-player WoW experience in Booty Bay.

## Quick Start

1. Download any MaNGOS Zero repack from **ac-web.org** or **mangoszero.sf.net**
2. Install XAMPP (apachefriends.org) — just MySQL needed
3. Copy our `sql/custom/import_all.sql` into the repack's SQL folder
4. Copy `config/bootybay.conf` into the mangosd folder
5. Start XAMPP MySQL
6. Run the repack's auto-installer (imports all SQL)
7. Run `launch.bat`
8. Open WoW 1.12.1 → connect to 127.0.0.1

## What's changed

- Spawn at Booty Bay inn
- Heavy tropical storms (50% chance)
- Custom fish: Golden Snapper, Stormfish, Bream, Reef Grunt, Sea King Salmon
- XP disabled — fishing is your progression
- Fishing skill levels 5x faster
- 100 gold starting money
- All flight paths unlocked
